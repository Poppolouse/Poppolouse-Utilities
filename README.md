# Poppolouse Utilities

A personal .NET utility library, organized into packages by area.

Licensed under the MIT License. See [LICENSE](LICENSE).

## Packages

- **`net`**: networking helpers, such as downloading files over HTTP.
- **`fm`**: file management helpers, such as writing streams to disk.

## Tests

The tests live in `tests/Poppolouse-Utilities.Tests` and use xUnit. Run them with:

```
dotnet test
```

The tests were written with the help of AI and reviewed by the author. The library code itself was written by the author.

## Requirements

- .NET 10 SDK
